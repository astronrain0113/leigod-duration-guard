本清单覆盖**只能在真实雷神客户端上完成**、无法用靶机替代的验收项，对应规格书 §三十五「最终验收标准」中仍标注 ⏳ 的部分。

> **纪律要求（规格书 §三十三）**：本清单中的所有条目**默认状态为"未验证"**。
> 只有在真实雷神上实际观察到预期结果后，才可把该项标记为"通过"，并把现象与证据（日志片段、报告文件、截图路径）填回本文件。
> **禁止**用"实现看起来没问题"或"靶机上通过了"来替代真机结论。

## 0. 前置准备（必须全部完成，否则后面的结论不可信）


| 编号 | 前置项 | 操作 | 为什么必须 |
| --- | --- | --- | --- |
| P-1 | 退出旧版程序 | 结束仍在后台运行的旧版 `ThunderGuard`（`pythonw.exe ...\ThunderGuard\main.py`，窗口标题「雷神时长保护助手」） | 它占用了单实例所需的资源、并会与自己争抢窗口判断；审计报告 §五已记录其仍在运行 |
| P-2 | 权限对齐 | 运行 `dist` 里的 exe（清单已声明 `requireAdministrator`，启动时会弹 UAC，点「是」即可）。用源码运行时需从**管理员命令行**启动 | 雷神的 `leigod.exe` / `leigod_launcher.exe` 清单本身就是 `requireAdministrator`（已实测），雷神**永远**以高完整性级别运行。本程序未提权时，Windows 的 UIPI 会**静默拒绝** `EnableMenuItem`，表现为「✕ 看起来灰了，其实还能点」——这是最隐蔽的失效方式 |
| P-3 | 确认写入位置 | 把程序放在有写权限的目录（如 `D:\Tools\LeigodGuard`），不要放 `Program Files` | 配置与日志写在 exe 旁边 |
| P-4 | 记录基线 | 运行 `dist\LeigodGuard\LeigodGuardCUI.exe --check`，保存输出 | 记录权限自检结论、版本、路径、UIA/OCR 可用性 |

**P-2 的判定方法**（不必猜）：

```bat
dist\LeigodGuard\LeigodGuardCUI.exe --check
```

看「权限自检」一段：
- `本程序管理员身份` 应为「是」；
- 若雷神已在运行，`雷神疑似管理员运行` 也应为「是」，且结论为「通过」；
- 若结论不是「通过」→ **先以管理员身份重启本程序**，再继续后面的任何测试。

> 补充判据（面板）：如果拦截没能真正生效，面板会显示
> 「关闭保护：**未能锁定雷神 ✕（权限不足）**」。
> 只要看到这行字，就说明关闭保护目前在裸奔，**不要**继续后面的用例。

## 阶段 1：真实雷神 UI 结构确认与三态识别

> 规格书 §三十 要求 Phase 1 未达到可靠识别之前不进入后续阶段。本阶段是**最高优先级**。

### G-1 窗口身份确认（对应 §十三）

| 项 | 内容 |
| --- | --- |
| 步骤 | ① 启动真实雷神，等主界面完全加载；② 运行 `LeigodGuardCUI.exe --window-inspector`；③ 再运行 `LeigodGuardCUI.exe --inspector` |
| 观察点 | 预期/待记录 |
| | 主窗口 HWND、窗口标题、**ClassName**（Electron 应用预期为 `Chrome_WidgetWin_1`，**以实测为准**） |
| | 进程名、进程路径、`version_f.txt` 版本号 |
| | WindowRect / 可见边框 / 客户区 / 宽 / 高 |
| | DPI 与缩放比、所在显示器 |
| | 是否缩到托盘（`minimized_to_tray`） |
| | 父链与子窗口结构（是否有中间层宿主窗口） |
| 产物 | `logs/inspector/leigod_full.png`、`duration_region.png`、`ocr.json`、`inspector.json` |
| 未通过的表现 | 找不到主窗口 / 类名与预期不符 / DPI 读取异常（例如 125% 缩放被读成 96） |

### G-2 三态识别准确性（对应 §六 / §七 / §八 / §九）

| 编号 | 操作 | 期望 | 实测 |
| --- | --- | --- | --- |
| G-2a | 在雷神里让总时长处于**运行**状态 → 运行 `--inspector` | `DurationState: RUNNING`，且能定位到「暂停时长」按钮的 Name / ControlType / AutomationId / BoundingRectangle / 是否支持 Invoke | ☐ |
| G-2b | 在雷神里点一次「暂停时长」（即变成 PAUSED）→ 运行 `--inspector` | `DurationState: PAUSED`，定位到「开启时长」按钮 | ☐ |
| G-2c | 把雷神窗口拖到屏幕外/最小化到托盘/或在页面切换瞬间执行 | `DurationState: UNKNOWN`（**绝不允许**在证据不足时给出 RUNNING/PAUSED） | ☐ |
| G-2d | **关键**：确认 UIA 是否真的能拿到可 Invoke 的按钮 | 若能 → 属于最优路径（后续暂停走 `InvokePattern`，不依赖坐标）；若不能 → 记录原因，后续依赖相对坐标 + OCR | ☐ |

**G-2d 的结论会直接影响后续所有验证的可靠性**，请务必记录：

```
是否通过 UI Automation 找到按钮 : 是 / 否
若能，是否支持 Invoke           : 是 / 否
若不能，UIA 树里能看到什么      : ____________________
识别到的按钮文案（原文）         : ____________________
```

> 若真实雷神的按钮文案**不是**「暂停时长」/「开启时长」，请立即记录原文，并在 `detection/ui_automation.py` 的 `PAUSE_LABELS` / `START_LABELS` 中补充——**在 Phase 1 通过之前，不要继续后面的阶段。**

## 阶段 2：暂停控制

| 编号 | 操作 | 期望 | 实测 |
| --- | --- | --- | --- |
| G-3a | 总时长 RUNNING 时，点面板上的「立即暂停时长」 | 变成 PAUSED；日志出现 `Pause requested` → `Pause method=...` → `Waiting for state update` → `DurationState=PAUSED`；**面板与雷神界面同时显示已暂停** | ☐ |

| G-3e | 抽查任意一次暂停操作 | 日志中**必然**出现"重读状态"这一步；不存在"点完即算成功" | ☐ |

## 阶段 3：关闭保护（最重要）

> 逐项对照规格书 §十二 / §十四 / §十五 / §十六。每一项都要记录"雷神是否被关掉"、"总时长最终状态"、"日志关键字"。

| 编号 | 场景 | 期望 | 实测 |
| --- | --- | --- | --- |
| G-4a | **测试 A**：总时长已 PAUSED，点雷神右上角 ✕ | 直接正常关闭；未点击任何按钮；日志 `Close allowed`；无"未保护关闭"告警 | ☐ |
| G-4b | **测试 B**：总时长 RUNNING，点雷神右上角 ✕ | 关闭被**暂时拦截** → 自动暂停 → 重新识别确认 PAUSED → 才真正关闭。日志顺序：`User requested Leigod close` → `Close request intercepted` → `Pause requested` → `Pause method=...` → `Waiting for state update` → `DurationState=PAUSED` → `Protection successful` → `Close allowed` | ☐ |
| G-4c | **测试 C**：让状态无法识别（最小化到托盘 / 拖到屏幕外 / 遮挡顶栏）后点 ✕ | **禁止关闭**，窗口存活；提示"无法确认雷神总时长是否正在运行。为防止剩余时长被继续消耗，雷神暂时无法关闭。请确认雷神状态后重试。"；日志 `[WARN] DurationState=UNKNOWN` + `[WARN] Close request blocked`；**零点击** | ☐ |
| G-4d | **测试 D**：RUNNING 但在暂停必然失败的状态下点 ✕（例如断网、或人为遮挡按钮） | 重试 3 次后仍 `BLOCK_PAUSE_FAILED`；**不自动放行**；日志 `[ERROR] Unable to verify paused state` | ☐ |
| G-4e | Alt+F4 触发关闭（与点 ✕ 同一条 `SC_CLOSE` 通路） | 与 G-4a~G-4d 行为一致 | ☐ |
| G-4f | 拦截可逆性 | 从托盘把「关闭保护」取消勾选后，✕ 恢复可用且能正常关闭 | ☐ |
| G-4g | 权限对照 | 故意用**非管理员**运行本程序、而雷神是管理员 → 观察关闭保护是否失效，并确认程序启动时有强提醒 | ☐ |

> G-4c 尤其重要：它验证的是"**UNKNOWN 不被当成 PAUSED**"这条最高纪律在真实雷神上是否成立。

## 附：真机验证所需的最小命令集

```bat
:: 0) 自检（含权限对照）
dist\LeigodGuard\LeigodGuardCUI.exe --check

dist\LeigodGuard\LeigodGuard.exe

:: 5) 启动器模式
dist\LeigodGuard\LeigodGuard.exe --launcher
```

诊断产物默认落盘在 `logs\`（`--out` 可指定其它目录）；运行日志在 `logs\guard.log`。
