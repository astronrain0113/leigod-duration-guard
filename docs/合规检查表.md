## 十三、关闭事件的实现方式

| 项 | 内容 |
| --- | --- |
| 规格要求 | 优先研究 Windows 原生关闭机制，重点检查 `WM_SYSCOMMAND` / `SC_CLOSE` / `WM_CLOSE`，以及雷神的 HWND / ClassName / Parent-Owner / PID / Process / Window hierarchy；先确定"雷神真正的关闭流程"；**不要简单用"鼠标是否在右上角"判断** |
| 结论 | **符合**（2026-09-29 真机实测后由"部分符合"升级） |
| 已达成 | ① 关闭链路已查清并落地为 `SC_CLOSE` 通路（`leigod/close_protection.py` 头部注释记录三种方案实测对比与取舍）；② 关闭意图**不靠"鼠标在右上角"**：`WH_MOUSE_LL` 低层钩子只入队全局左键坐标，消费端用 `WM_NCHITTEST`（**屏幕坐标**）向窗口自身询问命中码，`== HTCLOSE(20)` 才判为点了 ✕；另配 `WH_KEYBOARD_LL` 捕获 Alt+F4；③ 窗口层级诊断能力齐备（`diagnostics/window_inspector.py` 输出主窗口 HWND/Title/ClassName/PID/路径/版本/WindowRect/客户区/DPI+缩放/显示器/托盘态/父链+子窗口） |
| 真机复核结论 | **已完成（真实雷神 v11.3.2.9）**：① 窗口身份 `class=Chrome_WidgetWin_1`、`style=0x14C20000`（无 `WS_SYSMENU`）、`GetWindowRect == GetClientRect`（零非客户区，标题栏全自绘）；② **真实关闭流程与预期不同**：点 ✕ **不关窗、不走 `SC_CLOSE`**，而是弹雷神自己的确认框（「最小化到托盘」/「真的退出」）；③ 判据在真机 5 轮中全部正确命中热区（未出现"点在右上角就算"的误判）。见 `docs/真机发现-关闭保护架构问题.md`、`tests/out/verify_auto.json` |
| 残余未测 | 异常场景仍在 `docs/真机验证清单.md` G-4c/G-4d/G-4e/G-4f/G-4g 待验（UNKNOWN 阻止关闭、暂停失败、Alt+F4、可逆性、权限对照）。这些属 §十四/§十六 范畴，不影响本章结论 |
| 证据 | `tests/test_e2e_mock.py`（真实调用 `WM_NCHITTEST`，靶机返回 20=HTCLOSE 才产生关闭意图）；`tests/out/e2e_report.txt`；`tests/harness.py::hit_test`；**真机**：`tests/out/verify_auto.json`（5 轮，`window.class/pid/rect` + `hot_zone` + `click_point_owner` 均留档） |

## 十四、关闭保护的安全策略

| 项 | 内容 |
| --- | --- |
| 规格要求 | 情况1 PAUSED → 直接允许关闭；情况2 RUNNING → 拦截 → 暂停 → 等待 → 验证 → PAUSED → 允许关闭；情况3 UNKNOWN → **禁止关闭**并给出指定提示；情况4 暂停失败（点击失败/OCR 失败/UIA 失败/状态没变化/网络导致客户端未更新）→ **BLOCK CLOSE，不要自动放行** |
| 结论 | **符合** |

## 三十四、失败安全原则（Fail Safe）

| 项 | 内容 |
| --- | --- |
| 规格要求 | 采用 Fail Safe 而非 Fail Open：无法确认暂停 → 阻止关闭，而不是默认放行；因为最大风险不是"雷神暂时关不了"，而是"用户以为停了，结果几小时总时长被消耗" |
| 结论 | **符合** |
| 实现位置 | `core/state_machine.py::DurationState.safe_to_close`（仅 PAUSED 为 True）、`CloseDecision.BLOCK_UNKNOWN` / `BLOCK_PAUSE_FAILED`、`core/config.py`（`block_when_unknown = True`、`block_when_pause_failed = True` 为**默认值**） |
| 证据 | `tests/test_units.py::t_state_machine`（默认不允许把 UNKNOWN 当安全）；`tests/test_e2e_mock.py` 测试C/D（阻止关闭、靶机未收 `WM_CLOSE`、不自动放行） |

## 三十八、最终产品理念

| 项 | 内容 |
