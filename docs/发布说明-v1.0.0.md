## 关掉加速器之前，先替你把「计时」停下来

还在用加速器的「总时长」的话，大概遇过这个坑：**本来只是点 ✕ 关掉客户端，
结果那一晚的时长照扣** —— 因为关之前没有先暂停，而客户端关掉之后计时还在跑。

这个工具补上这一步。你照常点 ✕，它替你暂停，**而且确认暂停成功了才放你走**。

### 怎么用

1. 下载下面的 `LeigodGuard-v1.0.0.zip`，解压到任意目录；
2. 双击 **`立刻待命.bat`**（会弹一次 UAC —— 这是功能必需，原因见 README）；
3. 正常用加速器；想关它的时候照常点 ✕，工具会先暂停时长（约 2 秒）再放行。

### 三种状态，三种处理，没有"猜"

| 时长状态 | 点 ✕ 时它做什么 |
| --- | --- |
| 计时中 | 先暂停 → **重新读到「已暂停」** → 才放行关闭 |
| 已暂停 | 直接放行 |
| 读不出来 | **拦住关闭**，并告诉你下一步怎么处理 |

> 「读不出来就拦住」是刻意的：宁可让你多按一次「允许本次关闭」，
> 也不能让你以为停好了、结果时长还在跑。

### 这一版有什么

- **四级识别**：UI Automation → OCR → 颜色特征 → 坐标兜底（客户端不提供任何 API，全靠读界面）
- **关闭保护**：输入层吞掉 ✕ 的点击，确认暂停后原样重放，雷神自己的确认框照常出现
- **死手开关**：工具自己卡住或崩溃时，钩子会超时自动停止吞点 —— 不会把你锁死在"点不动 ✕"
- **自带诊断**：面板上一键生成诊断包（窗口/控件树/截图/OCR 逐行结果），提 Issue 时附上它
- 面板可拖动、可钉住、不抢焦点；托盘图标与面板同一套外观

### 系统要求与已知限制

- **Windows 10 / 11**
- **必须以管理员身份运行**：目标客户端是管理员权限，不提权就拦不住 ✕（README 有详细解释）
- 客户端改版后可能读不出状态 —— 遇到请提 Issue 并附诊断产物，通常只需更新几个关键词
- 杀软可能误报（PyInstaller 打包 + 鼠标钩子的常见组合），可以按 README 自己从源码跑
